## Mechanism and strong control

Build two lossless views of the SAME original P/G/R failure observations:

1. `case_local`: retain the case-local organization; explicitly separate each
   displayed expected result from its observed wrong result when a conservative
   diagnostic parser recognizes that boundary.
2. `obligation_overlap`: apply the SAME parsing, then group identical displayed
   expectations across observations. Keep different wrong results separate and
   list same-case support across Plain and the Graph/ordinary lineage.

Thus both arms receive normalized expectations, observations, original raw
feedback, public candidate sources and all47 tasks. The treatment is the
explicit cross-observation alignment and reuse of repeated expectations, not
extra oracle information, a stronger solver, or more calls. The exact generic
repair policy and instruction template are identical in both arms. The visible
view necessarily has a different layout and byte length; report these rather
than claiming byte-identical full inputs or token-equivalent representations.

Every `(task, case, candidate, raw diagnostic)` must reconstruct exactly from
either view. All899 records in the current original evidence satisfy this
invariant. Unknown diagnostics stay unknown and full status vectors remain in
the original feedback. Matching expected text is a potential obligation to
check against source and specification, not proof of the same root cause.
Graph and its ordinary repair do not count as independent votes. This is not a
semantic parser for arbitrary test frameworks; report that applicability limit.

No new probe author, hand-written task fix, task selection, source repair by the
coordinator, hidden test source, reference answer, benchmark lookup, or previous
final candidate is supplied. Preserve all source and input-integrity gates.
