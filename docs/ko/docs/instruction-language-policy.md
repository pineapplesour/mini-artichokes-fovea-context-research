# 지침 언어 정책

최종 업데이트 날짜: 2026-05-15 KST

이 저장소의 운영 지침은 이중 언어 계약으로 관리하되, 파일은 언어별로 분리합니다. 한국어 본문은 `docs/ko/...`에 두고, 영어 본문은 `docs/en/...`에 둡니다. 원래 위치의 문서는 각 언어 문서로 가는 짧은 안내 stub만 둡니다.

## 적용 대상

- 요구사항 문서.
- 엔진, 프론트, DB, 협업 계약.
- 팀별 작업 지시.
- 독립 실행 유지보수 절차.
- 레포 거버넌스와 권한 정책.
- 코퍼스 출처와 수집 정책 참고 문서.

## 한국어 문체

- 한국어 본문은 설명적 공식 문체로 작성합니다.
- 한국어 문장은 원칙적으로 `~입니다`, `~합니다`, `~해야 합니다`, `~하지 않아야 합니다` 형태로 끝납니다.
- 농담체, 과장 문구, 요청을 그대로 복사한 듯한 메타 서술을 쓰지 않습니다.
- 영어본보다 한국어본이 짧아져 핵심 요구가 빠지면 안 됩니다.

## 번역하지 않는 항목

- 코드 식별자.
- API field.
- HTTP endpoint.
- 파일 경로.
- CLI 명령어.
- 테스트 이름.
- 제품 key.
- GitHub handle.
- 환경변수 이름.

## 프론트 경계

- 공유 UI 커널은 동작만 소유합니다.
- 제품 스킨은 버튼 위치, 레이아웃, 카드 순서, 타이포그래피, 색, 애니메이션, 브랜드 표현을 소유합니다.
- 커널이 디자인 위치를 강제하면 모든 제품 디자인이 동시에 망가질 수 있으므로 금지됩니다.
- 제품별 JS가 제출, polling, 취소, source-window, 세션, i18n, 오프라인 동작을 복제하면 계약 위반입니다.

## 검증

- `python3 tools/verify_repo_contracts.py`는 `docs/ko`와 `docs/en` 양쪽 파일이 존재하는지 확인합니다.
- 한국어본은 영어본 기준으로 충분한 분량과 code fence 수를 유지해야 합니다.
- 원래 위치의 지침 파일은 본문을 직접 들고 있지 않고 split 문서 링크만 가져야 합니다.
